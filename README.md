# 🌿 Fertivitro — Landing Page & Linktree Oficial

Modernização e aprimoramento completo da presença digital da **Fertivitro Centro de Reprodução Humana** ([fertivitro.com.br](https://fertivitro.com.br/)), clínica pioneira e acreditada REDLARA com mais de 20 anos de excelência em medicina reprodutiva assistida em Moema, São Paulo.

---

## ✨ Destaques do Projeto

### 1. 🏥 Landing Page de Alta Conversão
- **Fotos e Vídeos Reais**: Fachada oficial (Av. Indianópolis, 529 - Moema), recepção VIP e acolhedora, laboratório limpo de FIV com cabines IVFtech, botijões criogênicos MVE da Fertibank a -196°C e Dr. Luiz Eduardo Albuquerque em procedimento cirúrgico.
- **Scroll Animations & Revelations**: Animações suaves de entrada com Framer Motion (whileInView, opacity, 	ranslateY).
- **Showcase de Vídeo 4K**: Player interativo com som e modo tela cheia demonstrando a rotina técnica do laboratório de FIV.
- **Abas de Tratamentos**: FIV de alta complexidade, ICSI, Inseminação Intrauterina (IIU), Congelamento de Óvulos e o Programa Social *Bebê em Casa*.
- **Galeria & Tour Virtual**: Grade interativa com lightbox ampliado de alta resolução.
- **Agendamento Inteligente**: Formulário modal com formatação automática de mensagem diretamente para o WhatsApp oficial.

### 2. 📱 Página Estilo Linktree (Bio)
Página responsiva criada com a identidade visual da Fertivitro, projetada para a bio do Instagram (@fertivitro) e WhatsApp:
- ⭐ **Avaliar no Google Meu Negócio**: Link direto para a janela de 5 estrelas e avaliação da Fertivitro no Google Reviews.
- 👤 **Adicionar Contato (vCard)**: Download dinâmico de cartão de contato .vcf em 1 clique com endereço, telefones, WhatsApp e CRM.
- 📍 **Rotas até a Clínica**: Rota direta no Google Maps / Waze até a Av. Indianópolis, 529 - Moema.
- 🌐 **Acesso à Landing Page Oficial**: Navegação integrada com o site principal.
- 📸 **Instagram Oficial**: Acesso direto ao perfil @fertivitro.
- 💬 **WhatsApp Oficial**: Atendimento direto pelo (11) 99546-6272.

## 🚀 Como Executar Localmente

1. Clone o repositório:
`ash
git clone https://github.com/leoleoyuuki/landingpage-fertivitro.git
cd landingpage-fertivitro
`

2. Instale as dependências:
`ash
npm install
`

3. Inicie o servidor de desenvolvimento:
`ash
npm run dev
`

4. Acesse no navegador:
- **Landing Page**: http://localhost:5173
- **Página Linktree**: http://localhost:5173/?links (ou #links)

---

## 📦 Build para Produção

`ash
npm run build
`
Os arquivos otimizados para deploy serão gerados na pasta dist/.
